## 2. Sequencing and tracks

1. **Orchestrator** commits this doc and `docs/adr/000-template.md`.
2. **Track A (scaffold), alone.** The Test-author writes the A tests (§3.7), then the A implementer builds the scaffold. It is reviewed and integrated, and CI must be green on the branch.
3. **Orchestrator stub step.** It runs `npm run bindings` and commits `src/contracts/bindings.ts` and `src/contracts/index.ts`. It adds the spike crates to the root `Cargo.toml` `members` and commits **stubs** for every spike API in §4–§6. Rust stubs have bodies of `todo!("M0 track X")`; TS stubs `throw new Error("not implemented")`. Each stub has a `package.json`/`Cargo.toml` and a `tsconfig.json`, so tests compile before any implementation exists.
4. **Test-authors for B, C, D** write failing tests against those stubs.
5. **Implementers B, C, D in parallel** in separate worktrees. Track C has three independent spikes, so it may use two worktrees: C-rust (typst, fts5) and C-web (foliate). That still keeps to at most 4 implementers.
6. Each track gets an independent Reviewer and is integrated one track at a time with the full gate. A Verifier runs after each; the Orchestrator writes the report.

### 2.2 Lockfiles

- There is one root `package-lock.json` (npm workspaces) and one root `Cargo.lock` (Cargo workspace).
- Implementers may update lockfiles locally to build. At integration, the Orchestrator **discards the track's lockfile changes** and regenerates them on the integration branch:

  ```
  git checkout <integration-branch> -- package-lock.json Cargo.lock
  npm install                 # re-resolves only what changed in workspace package.json files
  cargo metadata --format-version 1 --offline || cargo metadata --format-version 1
  ```

  Then it commits `chore: regenerate lockfiles after <track> merge`.
- New dependencies go only in the track's own `spikes/<name>/package.json` or `Cargo.toml`. Every new dependency is listed in the track's ADR, with its reason and license.

### 3.3 Rust interface (generated into `src/contracts/bindings.ts`)

```rust
// src-tauri/src/commands.rs
#[derive(Debug, Clone, serde::Serialize, specta::Type)]
#[serde(rename_all = "camelCase")]
pub struct AppInfo {
    pub name: String,          // always "InkSpark"
    pub version: String,       // env!("CARGO_PKG_VERSION")
    pub os: OsKind,
    pub arch: String,          // std::env::consts::ARCH
    pub tauri_version: String, // tauri::VERSION
}
#[derive(Debug, Clone, Copy, PartialEq, Eq, serde::Serialize, specta::Type)]
#[serde(rename_all = "lowercase")]
pub enum OsKind { Macos, Linux, Windows, Other }

#[tauri::command] #[specta::specta]
pub fn app_info() -> AppInfo;

// src-tauri/src/error.rs — the typed error pattern for all later commands (exported via .typ::<AppError>())
#[derive(Debug, thiserror::Error, serde::Serialize, specta::Type)]
#[serde(tag = "kind", content = "message", rename_all = "camelCase")]
pub enum AppError { #[error("not found: {0}")] NotFound(String), #[error("invalid input: {0}")] Invalid(String), #[error("io: {0}")] Io(String) }

// src-tauri/src/lib.rs
pub fn specta_builder() -> tauri_specta::Builder<tauri::Wry>; // commands: [app_info]; types: AppError
pub fn bindings_ts() -> Result<String, String>;               // renders the TS text (deterministic, with header comment)
pub fn run();                                                 // used by main.rs
```

`src-tauri/src/bin/export_bindings.rs` works as follows:
- `cargo run -p inkspark --bin export-bindings` writes `src/contracts/bindings.ts`.
- With `-- --check`, it compares the output to the file instead and exits 1 with a diff hint if they differ.
- The generated file starts with `// @generated by tauri-specta — do not edit` and is excluded from ESLint and Prettier.

Generated TS, roughly: `export const commands = { appInfo(): Promise<AppInfo> }`, plus the types `AppInfo`, `OsKind = "macos" | "linux" | "windows" | "other"` and `AppError`.

`src/contracts/index.ts` (Orchestrator) re-exports `commands` and the types.

```ts
export type Flags = Readonly<Record<FlagName, boolean>>;
export function parseFlagOverrides(raw: string | undefined): { enabled: FlagName[]; disabled: FlagName[]; unknown: string[] };
```

Flags are build-time and frontend-only in M0. If Rust needs flags later, that goes to the Orchestrator as a contract request. `docs/feature-flags.md` covers adding a flag, the override syntax (`VITE_INKSPARK_FLAGS="readerView,-dictation" npm run tauri dev`), and the rule that defaults stay `false` until the feature's milestone accepts it.

### 3.5 Lint, format and strictness

- **`eslint.config.js`** (flat config):
  - Base: `tseslint.configs.strictTypeChecked` + `stylisticTypeChecked`, plus `eslint-plugin-react-hooks`.
  - Ignores: `dist`, `target`, `vendor/**`, `src/contracts/bindings.ts`, `**/results/**`, `**/playwright-report/**`.
  - The **fs-write ban** applies to `src/**` and `spikes/*/src/**`:
    - `no-restricted-imports` bans these paths: `fs`, `node:fs`, `fs/promises`, `node:fs/promises`, `@tauri-apps/plugin-fs`, `@tauri-apps/api/fs`. It also bans the patterns `@tauri-apps/plugin-fs/*`, `node:fs/*` and `fs/*`. The message is: "Writes go through the Rust storage module (CLAUDE.md)."
    - `no-restricted-syntax` covers `ImportExpression[source.value=/^(node:)?fs(\/|$)|^@tauri-apps\/(plugin-fs|api\/fs)/]` and `CallExpression[callee.name='require'][arguments.0.value=/^(node:)?fs/]`.
- **Prettier**: `printWidth: 100`, `endOfLine: "lf"`.
- **`.gitattributes`**: `* text=auto eol=lf`; `*.rtf *.scrivx *.epub *.png *.ttf *.otf -text`; `spikes/scriv-parser/fixtures/** -text`.
- **TS**: `strict`, `noUncheckedIndexedAccess`, `exactOptionalPropertyTypes`, `noImplicitOverride`, `verbatimModuleSyntax`. `@ts-ignore` is banned via `@typescript-eslint/ban-ts-comment` (`ts-expect-error` is allowed only with a description).
- **Rust**:
  - Every crate root has `#![forbid(unsafe_code)]` and `[lints] workspace = true`, except `spikes/macos-speech` (§6.1).
  - `clippy.toml` contains `disallowed-methods = ["std::fs::write", "std::fs::File::create"]` for awareness. In M0 it is warning-free because only the spikes' bench bins write result files, and they use `#[allow(clippy::disallowed_methods)]` with a comment. The `storage` module arrives in M1.
- **`deny.toml`**:
  - `[advisories]`: yanked = deny.
  - `[licenses]` allow: MIT, Apache-2.0, Apache-2.0 WITH LLVM-exception, BSD-2-Clause, BSD-3-Clause, ISC, MPL-2.0, Zlib, Unicode-3.0, Unicode-DFS-2016, CC0-1.0. Anything else (e.g. OFL-1.1 for typst-assets fonts, CDLA-Permissive-2.0, BSL-1.0) needs an explicit `exceptions` entry with a reason comment, plus a mention in the relevant ADR.
  - `[bans]`: multiple-versions = "warn".
  - `[sources]`: unknown-registry and unknown-git = deny.

### 3.8 CI (`.github/workflows/ci.yml`)

Triggers: push to any branch, and PRs to `main`. Concurrency cancels in-progress runs per ref. Each job uses `actions/setup-node@v4` (Node 22, npm cache) and `Swatinem/rust-cache@v2`. Ubuntu jobs apt-install `libwebkit2gtk-4.1-dev libappindicator3-dev librsvg2-dev patchelf libxdo-dev libssl-dev build-essential`. Windows jobs run `git config --global core.longpaths true`.

| Job | Runs on | Steps |
|---|---|---|
| `check (${{os}})` | matrix ubuntu-24.04, macos-15, windows-2022 | `npm ci` → `npm run lint` → `npm run typecheck` → `npm test` → `cargo fmt --all -- --check` → `cargo clippy --workspace --all-targets -- -D warnings` → `cargo test --workspace` → app build: `npm run tauri build -- --ci --no-bundle` on ubuntu and windows. On ubuntu only, this job also runs `npm run bindings:check`. |
| `build-macos` | macos-15 | `rustup target add aarch64-apple-darwin x86_64-apple-darwin` → `npm run tauri build -- --ci --target universal-apple-darwin --bundles app,dmg` (output under `target/universal-apple-darwin/release/bundle/`). The dmg step is retried once and has a 20-min timeout. Smoke: start `target/universal-apple-darwin/release/bundle/macos/InkSpark.app/Contents/MacOS/inkspark` in the background, sleep 15, `kill -0` must succeed, then kill. Then `ditto -c -k --keepParent` the .app. Upload artifact `InkSpark-macos-universal-unsigned` (the .app zip + `.dmg`, 30-day retention). The .app upload is unconditional; the dmg upload runs `if: success()`. |
| `e2e-linux` | ubuntu-24.04 | Extra packages: `webkit2gtk-driver xvfb`. Then `cargo install tauri-driver --version 2.1.0 --locked`, `npm run tauri build -- --debug --no-bundle`, `xvfb-run -a npm run test:e2e`. `wdio.conf.ts` starts and stops `tauri-driver` and points `tauri:options.application` at `target/debug/inkspark`. |
| `audit` | ubuntu-24.04 | `EmbarkStudios/cargo-deny-action@v2` (check all), then `npm ci && npm run audit`. |

Branch protection on `main` requires `check` ×3, `build-macos`, `e2e-linux` and `audit`.

**E2E decision (record in ADR 007): include it, required, ubuntu only.**
- tauri-driver officially supports Linux through WebKitWebDriver, and the job is cheap.
- It sets up the harness that M1's "write → crash → reopen" E2E needs.
- It cannot run locally: there is no `WebKitWebDriver` in the container, and we may not install it. Developers rely on CI for it.
- Fallback: if the job flakes twice during M0 for infrastructure reasons, it becomes non-required with an ADR note, and is fixed in M1.

**`.github/workflows/spikes.yml`** (owned by A; jobs are skipped with `if: hashFiles('<spike>/package.json' or 'Cargo.toml') != ''` until the spike exists):
- These jobs are **not** branch-protection gates.

### 5.3 FTS5 encyclopedia spike (`spikes/fts5-encyclopedia`, crate `inkspark-spike-fts`)

```rust
pub fn read_project(scriv_dir: &std::path::Path) -> Result<ScrivProject, ScrivError>; // opens files read-only; missing content gives a warning, not an error
```

Tests (`spikes/scriv-parser/tests/`):
- `golden.rs`: for every fixture except malformed, `read_project` serialized to JSON equals `expected.json`.
- `malformed.rs`: malformed returns `Err(Xml)` without panicking; a non-scriv dir returns `Err(NotAScrivPackage)`.
- `rtf.rs`: unit cases for each control word above, `\uN` with a fallback character skipped, `\'hh` decoded via cp1252, nested groups, unknown destinations ignored.
- `source_untouched.rs`: hashes every file (SHA-256 via a small dev dependency, or a byte compare) plus mtimes under each fixture before and after `read_project`, and asserts they are equal. This is data-safety invariant 2.
- `props.rs` (proptest, 2,000 cases in CI): `rtf_to_doc(&arbitrary_bytes)` and `parse_scrivx(&arbitrary_string)` never panic.
- `perf.rs`: `#[ignore]`, generates 1,000 docs, asserts `read_project` < 2 s in release.

Go/no-go:
- all goldens exact;
- zero panics in proptest;
- sources untouched;
- 1,000-doc project parsed in < 2 s (macos-15 release, recorded via `cargo test --release -- --ignored perf`).

## 9. Risks and mitigations

| # | Risk | Mitigation |
|---|---|---|
| R1 | tauri-specta/specta are release candidates and their pins drift (specta rc.27 exists, but tauri-specta rc.26 needs `=rc.26`). | Exact `=` pins for tauri-specta, specta and specta-typescript. Bindings are checked in CI. Upgrades go only through the Orchestrator, with regenerated bindings. |
| R2 | Non-deterministic binding output (ordering, line endings). | `bindings_ts()` determinism test; LF normalization in the compare; file excluded from Prettier. |
| R3 | dmg bundling flakes on CI (AppleScript/Finder in `bundle_dmg.sh`). | Retry once, 20-min timeout. Always upload the .app zip. If the dmg keeps failing, use `--skip-jenkins`-style options or a hdiutil fallback, recorded in ADR 007. |
| R4 | Playwright WebKit ≠ WKWebView/WebKitGTK exactly. | Decide on macos-15 WebKit. The ADR states the gap. Vertical and foliate are reconfirmed in the real app behind flags (M1/M5 manual checks on the user's Mac). |
| R5 | objc2 block and run-loop callbacks (synthesizer buffer callback, recognizer tasks) deadlock or never fire off the main thread. | Pump `NSRunLoop` with a timeout in the spike, use typed `SpeechError::Timeout`, and keep swift-rs as the fallback (ADR 005). Note that a CI runner may have no voices: then the test is reported, and the ADR relies on the manual run. |
| R6 | TCC prompts crash a process without an Info.plist. | Embedded `__info_plist` section in `speech-spike`. CI never requests authorization. |
| R7 | Windows: CRLF corrupting fixtures, long paths, path separators, npm script portability. | `.gitattributes`; `core.longpaths`; `Path::join` with `env!("CARGO_MANIFEST_DIR")`; no shell-specific npm scripts (bindings check is a Rust bin, not `git diff`). |
| R8 | Heavy Rust spikes (typst, rusqlite bundled) slow every `check` job. | rust-cache; spike tests use small inputs; benches only in `spikes.yml`. If the check job exceeds 30 min, the Orchestrator may add `--exclude` for spike crates on Windows, with an ADR note. |
| R9 | The user's Mac CPU is unknown. | **Orchestrator decision:** build `universal-apple-darwin`, which runs on both Apple Silicon and Intel. It costs extra build time. |
| R10 | Vite 8 / plugin-react 6 / ESLint 10 are recent majors and may have breakage. | Fallback versions are documented in §3.2. Pick the first set that works and record it in ADR 007. |
| R11 | foliate-js needs CSP beyond the baseline (blob iframes, inline styles). | The CSP equality test makes this explicit. Changes go through an Orchestrator contract request; `unsafe-eval` means No-go. |
| R12 | Synthetic corpora and fixtures are unrepresentative (real Wikipedia/Scrivener/Gutenberg data is blocked locally). | Documented as an ADR follow-up: a CI-side real-data step (M6/M7). No local workarounds. |
| R13 | `npm audit` fails on a transitive dev-dependency advisory with no fix. | `--audit-level=high`. Any accepted exception is recorded in ADR 007 with an expiry date, never silently ignored. |
| R14 | cargo-deny license failures (OFL fonts, CDLA, BSL). | Explicit `exceptions` per crate with a reason, in deny.toml (Orchestrator-owned after A). |
| R15 | A lockfile merge conflicts across parallel tracks. | §2.2: the Orchestrator regenerates lockfiles at each integration; tracks never resolve lockfile conflicts themselves. |
